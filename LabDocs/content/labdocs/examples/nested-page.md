# Nested Page Example

This file demonstrates recursive content discovery.

Its filesystem location is:

```text
content/
└── labdocs/
    └── examples/
        └── nested-page.md
```

LabDocs exposes the same hierarchy in its route:

```text
/docs/labdocs/examples/nested-page
```

The `labdocs` and `examples` folders also appear as nested groups in the navigation.
